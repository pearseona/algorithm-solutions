# 최소직사각형

## 접근방식

- 명함을 회전할 수 있으므로 모든 명함의 짧은 변과 긴 변을 구분
- `Math.min()`으로 짧은 변을, `Math.max()`로 긴 변을 구함
- 짧은 변 중 가장 큰 값을 `maxShort`에 저장
- 긴 변 중 가장 큰 값을 `maxLong`에 저장
- 두 값을 곱하여 모든 명함을 넣을 수 있는 최소 지갑 넓이를 반환

## 사용한 알고리즘

- 배열 순회와 최댓값 갱신
- 모든 명함의 짧은 변끼리, 긴 변끼리 같은 방향으로 맞추어 회전을 처리
- 지갑의 짧은 변과 긴 변이 각각 `maxShort`, `maxLong`이면 모든 명함이 들어감
- 지갑의 짧은 변을 더 줄이면 짧은 변이 `maxShort`인 명함이 들어가지 않고, 긴 변을 더 줄이면 긴 변이 `maxLong`인 명함이 들어가지 않으므로 최소 크기가 됨

## 시간 복잡도

- 명함 수를 n이라고 할 때, 모든 명함을 한 번씩 확인하므로 시간 복잡도는 O(n)
- 일정한 개수의 변수만 사용하므로 추가 공간 복잡도는 O(1)

## 학습 메모

- `sizes[i][0]`과 `sizes[i][1]`은 i번째 명함의 두 변의 길이
- `Math.min(a, b)`는 작은 값을 반환하고, `Math.max(a, b)`는 큰 값을 반환
- `maxShort = Math.max(maxShort, shortSide)`는 지금까지 확인한 짧은 변의 최댓값을 갱신
- `maxLong = Math.max(maxLong, longSide)`는 지금까지 확인한 긴 변의 최댓값을 갱신
- 예를 들어 `[60, 50]`, `[30, 70]`의 긴 변을 같은 방향으로 맞추면 `[60, 50]`, `[70, 30]`이 됨
- 두 명함을 모두 넣으려면 긴 변은 70, 짧은 변은 50이 필요하므로 지갑 넓이는 3500
- 명함 배열을 직접 변경하지 않고 두 변의 최솟값과 최댓값으로 회전을 반영
- `Math` 클래스는 별도의 import 없이 사용 가능
