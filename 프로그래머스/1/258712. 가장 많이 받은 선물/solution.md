# 가장 많이 받은 선물

## 접근방식

- 친구 이름을 배열 인덱스로 사용할 수 있도록 `HashMap`에 이름과 번호를 저장
- `count[i][j]`에 i번째 친구가 j번째 친구에게 준 선물 개수를 저장
- 선물 기록을 읽으면서 준 사람의 선물 지수는 1 증가시키고, 받은 사람의 선물 지수는 1 감소
- 친구를 두 명씩 비교하여 다음 달에 선물을 받을 사람을 결정
- 두 사람 사이에서 선물을 더 많이 준 사람이 다음 달에 선물을 하나 받음
- 주고받은 횟수가 같으면 선물 지수가 더 큰 사람이 하나 받음
- 선물 지수까지 같으면 두 사람은 다음 달에 선물을 주고받지 않음
- 친구별로 다음 달에 받을 선물 개수를 계산하고 최댓값을 반환

## 사용한 알고리즘

- 해시맵을 이용한 이름과 인덱스 연결
- 2차원 배열을 이용한 선물 기록 집계
- 이중 반복문으로 모든 친구 쌍을 확인하는 시뮬레이션
- 모든 선물 기록의 집계를 마친 뒤 다음 달 결과를 계산

## 시간 복잡도

- 친구 수를 n, 선물 기록 수를 m이라고 할 때, 이름과 번호를 저장하는 데 O(n)
- 선물 기록 집계에 평균 O(m)
- 모든 친구 쌍을 비교하는 데 O(n²)
- 전체 평균 시간 복잡도는 O(m + n²)
- 선물 기록을 저장하는 2차원 배열 때문에 공간 복잡도는 O(n²)

## 학습 메모

- `index.put(friends[i], i)`로 친구 이름에 번호를 부여
- `gift.split(" ")`으로 선물을 준 사람과 받은 사람의 이름을 분리
- `count[giver][receiver]++`로 두 사람 사이의 선물 기록을 누적
- `giftIndex`는 전체 친구에게 준 선물 수에서 받은 선물 수를 뺀 값
- `count[i][j]`와 `count[j][i]`를 비교하면 두 사람 사이에서 누가 더 많이 줬는지 알 수 있음
- 두 사람이 선물을 주고받은 적이 없으면 양쪽 횟수가 모두 0이므로, 횟수가 같은 경우에 포함하여 선물 지수를 비교
- `j = i + 1`부터 시작하면 자기 자신을 제외하고 각 친구 쌍을 한 번씩만 확인할 수 있음
- `nextMonth`에는 다음 달에 받을 선물 개수를 별도로 저장
- 다음 달 계산 중에는 기존의 `count`와 `giftIndex`를 변경하지 않아야 모든 친구 쌍에 같은 기준을 적용할 수 있음
- `Math.max(answer, received)`로 다음 달에 받을 선물 개수의 최댓값을 갱신
