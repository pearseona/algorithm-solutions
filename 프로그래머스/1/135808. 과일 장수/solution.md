# 과일 장수

## 접근방식

- `score` 배열을 오름차순으로 정렬
- 점수가 높은 사과부터 `m`개씩 묶어 상자를 구성
- 각 상자의 가격은 상자에 담긴 사과 중 가장 낮은 점수에 `m`을 곱한 값
- 첫 번째 상자의 최저 점수 인덱스인 `score.length - m`부터 시작
- 인덱스를 `m`씩 감소시키며 각 상자의 가격을 합산
- `m`개를 채우지 못한 나머지 사과는 제외
- 합산한 최대 이익을 반환

## 사용한 알고리즘

- 정렬과 그리디 알고리즘
- 높은 점수의 사과끼리 묶어 낮은 점수의 사과가 상자의 가격을 낮추는 것을 최소화
- 가장 높은 점수의 사과 `m`개를 한 상자로 묶고, 남은 사과에도 같은 방식을 반복

## 시간 복잡도

- 사과의 개수를 n이라고 할 때, 배열 정렬에 O(n log n)
- 상자별 가격 합산에 O(n / m)
- 전체 시간 복잡도는 O(n log n)

## 학습 메모

- `Arrays.sort(score)` : 사과 점수를 오름차순으로 정렬
- `score.length - m` : 뒤에서부터 `m`개를 묶었을 때 해당 상자의 최저 점수가 위치한 인덱스
- `score[i] * m` : 현재 상자의 최저 점수에 사과 개수를 곱하여 상자 가격 계산
- `i -= m` : 다음 상자의 최저 점수 인덱스로 이동
- `i >= 0` 조건으로 사과가 `m`개 이상 남아 있는 경우에만 상자를 구성
- 사과 개수가 `m`보다 적으면 반복문이 실행되지 않아 0을 반환
- 최대 점수 `k`는 정렬을 이용한 풀이에서는 직접 사용하지 않음
- `Arrays.sort(score)`는 입력 배열의 순서를 변경함
