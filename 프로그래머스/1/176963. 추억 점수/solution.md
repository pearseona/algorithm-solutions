# 추억 점수

## 접근방식

- `name`과 `yearning`의 같은 인덱스를 이용해 이름별 그리움 점수를 `HashMap`에 저장
- 사진 개수만큼의 길이를 가진 `answer` 배열을 생성
- 각 사진에 등장하는 사람의 이름을 확인하고 맵에서 점수를 조회
- 등록되지 않은 이름은 0점으로 처리
- 조회한 점수를 해당 사진의 `answer[i]`에 합산
- 사진 순서대로 계산한 점수 배열을 반환

## 사용한 알고리즘

- 해시맵을 이용한 이름별 점수 조회
- 이중 반복문으로 각 사진과 사진 속 인물을 순회하며 점수를 합산

## 시간 복잡도

- 등록된 사람 수를 n, 모든 사진에 등장하는 인물 수의 합을 p라고 할 때, 맵 생성에 평균 O(n)
- 사진 속 인물의 점수 조회와 합산에 평균 O(p)
- 전체 평균 시간 복잡도는 O(n + p)
- 사진 개수를 m이라고 할 때, 맵과 결과 배열을 저장하므로 공간 복잡도는 O(n + m)

## 학습 메모

- `Map<String, Integer>`는 문자열 이름을 키로, 정수 점수를 값으로 저장
- `scores.put(name[i], yearning[i])`로 이름과 해당 점수를 연결
- `photo.length`는 전체 사진 수
- `photo[i].length`는 i번째 사진에 등장하는 사람 수
- `photo[i][j]`는 i번째 사진 속 j번째 사람의 이름
- `scores.getOrDefault(person, 0)`은 이름이 있으면 해당 점수, 없으면 0을 반환
- `int[]` 배열은 생성 시 모든 값이 0으로 초기화되므로 바로 점수를 누적할 수 있음
- `answer[i] += 점수`로 i번째 사진의 총점을 계산
- 예를 들어 `"may"`가 5점, `"kein"`이 10점이고 `"deny"`는 등록되지 않았다면, `["may", "kein", "deny"]` 사진의 점수는 15
