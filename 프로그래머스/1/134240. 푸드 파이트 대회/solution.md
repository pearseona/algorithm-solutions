# 푸드 파이트 대회

## 접근방식

- `food[0]`은 물이므로 1번 음식부터 순서대로 확인
- 각 음식의 개수를 2로 나눈 몫 `food[i] / 2`를 선수 한 명에게 배정
- 배정한 개수만큼 음식 번호 `i`를 `StringBuilder`에 추가해 왼쪽 배치를 완성
- 왼쪽 배치를 문자열로 저장한 뒤, `reverse()`로 뒤집어 오른쪽 배치를 생성
- 왼쪽 배치, 물을 나타내는 `"0"`, 오른쪽 배치를 이어 붙여 반환

## 사용한 알고리즘

- 반복문으로 음식별 배정 개수를 계산하고, 좌우 대칭을 이용해 전체 문자열을 구성
- 두 선수는 서로 반대쪽 끝에서 시작해 같은 순서로 음식을 먹으므로, 오른쪽 배치는 왼쪽 배치를 뒤집은 형태가 됨

## 시간 복잡도

- `food`의 길이를 `n`, 결과 문자열의 길이를 `L`이라고 하면 음식 종류를 확인하는 데 `O(n)`, 문자열을 만들고 뒤집는 데 `O(L)`이 필요
- 전체 시간 복잡도는 `O(n + L)`
- `StringBuilder`와 좌우 배치 문자열을 저장하므로 추가 공간 복잡도는 `O(L)`

## 학습 메모

- Java의 정수 나눗셈에서 `3 / 2`는 `1`이므로, 홀수 개의 음식에서 남는 하나는 배치에서 빠짐
- `left.append(i)`는 음식의 개수가 아니라 **음식 번호**를 문자열에 붙임
- `reverse()`는 `StringBuilder` 자체를 변경하므로, 뒤집기 전에 `left.toString()`으로 왼쪽 배치를 저장
- `food = [1, 3, 4, 6]`이면 왼쪽은 `"122333"`, 오른쪽은 `"333221"`이므로 결과는 `"1223330333221"`
