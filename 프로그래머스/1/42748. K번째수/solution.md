# K번째수
## 접근방식
- 명령의 개수만큼 결과 배열을 생성
- commands를 순회하면서 각 명령의 i, j, k를 읽음
- 원본 배열의 i번째부터 j번째까지 복사하고, 복사한 배열을 오름차순으로 정렬
- 정렬한 배열의 k번째 값을 결과 배열에 저장
- 모든 명령을 처리한 뒤 결과 배열을 반환

## 사용한 알고리즘
- 배열의 구간 복사 및 정렬
- 모든 명령을 처리한 뒤 결과 배열을 반환

## 시간 복잡도
- 원본 배열의 길이를 n, 명령의 개수를 m이라고 할 때, 명령 하나의 구간 복사는 최대 O(n), 정렬은 최대 O(n log n)
- 모든 명령을 처리하는 전체 시간 복잡도는 최악의 경우 O(m × n log n)
- 결과 배열에 O(m), 현재 명령의 복사 배열에 최대 O(n)이 필요하므로 추가 공간 복잡도는 O(m + n)

## 학습 메모
- `new int[commands.length]` : 명령 하나당 결과 하나가 나오므로 명령의 개수만큼 결과 배열을 생성
- 문제에서 말하는 "i번째"는 1부터 세지만, Java 배열의 인덱스는 0부터 시작하므로 시작 인덱스는 i - 1
- `Arrays.copyOfRange(array, i - 1, j)` : 원본 배열에서 지정한 구간을 복사하여 새로운 배열을 생성. 시작 인덱스는 포함하고 끝 경계는 포함하지 않음
- `Array.sort(cut)` : 복사한 배열 cut을 오름차순으로 정렬. 배열 자체를 변경하며, 정렬된 새 배열을 반환하는 메서드는 아님
- `cut[k-1]` : 정렬한 배열의 k번째 값. k가 3이면 인덱스 2의 값을 가져옴
- `answer[c] = cut[k - 1]`: 현재 명령에서 구한 값을 결과 배열의 c번째 위치에 저장
