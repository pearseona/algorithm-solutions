# 문자열 나누기

## 접근방식

- 문자열을 왼쪽부터 한 글자씩 확인
- 새로운 조각을 시작할 때 첫 글자를 기준 문자로 설정
- 기준 문자와 같은 글자의 수를 `same`, 다른 글자의 수를 `different`에 저장
- 두 횟수가 같아지면 한 조각이 완성된 것이므로 `answer`를 1 증가
- 두 횟수를 0으로 초기화하고 다음 글자부터 새로운 조각을 시작
- 모든 글자를 확인한 뒤 남은 부분이 있으면 한 조각으로 계산
- 분리한 문자열의 개수를 반환

## 사용한 알고리즘

- 문자열 순회 및 시뮬레이션
- 문제의 규칙에 따라 두 횟수가 처음 같아지는 순간마다 분리
- 실제로 문자열을 잘라내는 대신 횟수를 초기화하여 다음 조각을 처리

## 시간 복잡도

- 문자열의 길이를 n이라고 할 때, 각 문자를 한 번씩 확인하므로 시간 복잡도는 O(n)
- 일정한 개수의 변수만 사용하므로 추가 공간 복잡도는 O(1)

## 학습 메모

- `s.charAt(i)`는 문자열의 i번째 문자를 반환
- 새로운 조각의 첫 글자를 읽을 때 `same == 0`이므로 기준 문자를 갱신
- 기준 문자와 다른 글자들은 종류와 관계없이 모두 `different`에 합산
- `same == different`가 되면 조각 개수를 늘리고 두 횟수를 함께 초기화
- 반복문 종료 후 `same > 0`이면 아직 계산하지 않은 조각이 남아 있다는 의미
- 마지막 조각은 두 횟수가 달라도 하나로 계산
- `"banana"`는 `"ba"`, `"na"`, `"na"`로 나뉘므로 결과는 3
- `"aaa"`는 두 횟수가 같아지는 순간이 없으므로 마지막에 남은 전체 문자열을 한 조각으로 계산
