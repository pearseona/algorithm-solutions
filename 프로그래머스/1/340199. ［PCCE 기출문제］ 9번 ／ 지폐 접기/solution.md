# 지폐 접기

## 접근방식

- 지폐를 접은 횟수를 저장할 변수 `answer`를 0으로 초기화
- 지폐와 지갑의 짧은 변끼리, 긴 변끼리 비교하여 지갑에 들어가는지 확인
- 지폐의 짧은 변이 지갑의 짧은 변보다 크거나, 긴 변이 지갑의 긴 변보다 크면 접기를 반복
- 지폐의 두 변 중 더 긴 변을 2로 나눔
- 지폐를 한 번 접을 때마다 `answer`를 1 증가
- 지폐가 지갑에 들어가면 반복을 종료하고 접은 횟수를 반환

## 사용한 알고리즘

- 구현 및 시뮬레이션
- 문제에서 정한 규칙에 따라 긴 변을 반으로 접는 과정을 그대로 구현
- 짧은 변과 긴 변을 각각 비교하여 지폐를 90도 회전하는 경우까지 처리

## 시간 복잡도

- 지폐의 초기 두 변 중 최댓값을 M이라고 할 때, 각 변은 접힐 때마다 절반으로 감소
- 두 변을 줄이는 데 필요한 총 반복 횟수는 O(log M)
- 전체 시간 복잡도는 O(log M)
- 별도의 배열이나 자료구조를 생성하지 않으므로 추가 공간 복잡도는 O(1)

## 학습 메모

- `Math.min(a, b)` : 두 값 중 작은 값을 반환
- `Math.max(a, b)` : 두 값 중 큰 값을 반환
- 짧은 변끼리, 긴 변끼리 비교하면 실제로 배열의 값을 바꾸거나 지폐를 회전할 필요가 없음
- `||`를 사용하여 짧은 변과 긴 변 중 하나라도 지갑보다 크면 접기를 계속함
- 지폐와 지갑의 변 길이가 같으면 들어갈 수 있으므로 `>=`가 아닌 `>`로 비교
- `bill[0] /= 2` : `bill[0]`을 2로 나눈 값을 다시 저장
- 양의 정수끼리 나누므로 길이가 홀수인 경우 소수점 이하는 자동으로 버려짐
- 두 변의 길이가 같으면 `else`에서 `bill[1]`을 접어도 결과에 문제가 없음
- 처음부터 지갑에 들어가는 지폐는 반복문이 실행되지 않아 0을 반환
- `bill` 배열의 값을 직접 변경하며 접힌 지폐의 크기를 반영
