# 신고 결과 받기

## 접근방식

- `report`를 `HashSet`에 넣어 같은 사람이 같은 대상을 여러 번 신고한 기록을 한 건으로 처리
- 중복을 제거한 신고 목록을 순회하며 `reportedCount`에 사람별로 신고당한 횟수를 저장
- 같은 목록을 다시 순회하며 신고당한 사람이 `k`회 이상 신고됐는지 확인
- 정지 조건을 만족하면 그 사람을 신고한 유저의 메일 수를 `mailCount`에서 1 증가
- `id_list` 순서대로 받은 메일 수를 `answer` 배열에 담아 반환

## 사용한 알고리즘

- `HashSet`으로 중복 신고를 제거하고, `HashMap`으로 아이디별 횟수를 집계
- 첫 번째 순회에서는 신고 기록의 뒤쪽 아이디를 세어 정지 여부를 판단할 수 있게 함
- 두 번째 순회에서는 정지된 사람을 대상으로 한 신고만 골라 앞쪽 아이디의 메일 수를 늘림

## 시간 복잡도

- 전체 신고 수를 `R`, 이용자 수를 `N`이라고 할 때, 신고 문자열의 길이가 최대 21이므로 평균 시간 복잡도는 `O(R + N)`
- 중복을 제거한 신고 수를 `U`라고 할 때, 신고 집합과 아이디별 집계 정보를 저장하므로 추가 공간 복잡도는 `O(U + N)`

## 학습 메모

- `"a b"`를 `split(" ")`으로 나누면 `parts[0]`은 신고한 사람 `a`, `parts[1]`은 신고당한 사람 `b`
- `getOrDefault(id, 0)`을 사용하면 아직 집계되지 않은 아이디의 횟수를 0부터 시작할 수 있음
- 정지 기준은 `k`회 **이상**이므로 `reportedCount.get(reported) >= k`로 비교
- 두 번째 순회에서 조회하는 신고 대상은 첫 번째 순회에서 모두 집계했으므로 `reportedCount.get(reported)`로 바로 조회할 수 있음
- 메일을 받지 않은 사람은 `mailCount`에 없으므로 결과 배열에 0을 저장
- `HashSet`의 순회 순서와 관계없이, 마지막에 `id_list`를 순회하면 요구된 순서대로 결과를 반환할 수 있음
