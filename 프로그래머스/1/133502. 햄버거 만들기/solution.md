# 햄버거 만들기

## 접근방식

- 재료를 순서대로 읽으면서 `stack` 배열에 하나씩 쌓음
- 재료를 추가할 때마다 맨 위에 있는 4개가 `1, 2, 3, 1`인지 확인
- 순서가 맞으면 `size`를 4 줄여 재료를 제거하고, 포장한 햄버거 개수를 1 증가
- 모든 재료를 처리한 뒤 포장한 햄버거 개수를 반환

## 사용한 알고리즘

- 배열로 구현한 스택
- 재료가 하나 추가될 때 새로 완성되는 햄버거는 방금 넣은 재료를 포함하므로, 스택의 맨 위 4개만 확인하면 됨
- 햄버거를 포장한 뒤에도 아래에 남은 재료는 다음에 들어오는 재료와 함께 사용할 수 있음

## 시간 복잡도

- 재료의 개수를 `n`이라고 할 때, 각 재료를 한 번씩 읽고 최대 4개만 비교하므로 시간 복잡도는 `O(n)`
- 재료를 담는 배열의 크기가 `n`이므로 추가 공간 복잡도는 `O(n)`

## 학습 메모

- `size`는 현재 쌓인 재료의 개수이자 다음 재료를 넣을 인덱스
- `size >= 4`를 먼저 확인하면 재료가 4개 미만일 때 음수 인덱스에 접근하는 것을 막을 수 있음
- `stack[size - 4]`부터 `stack[size - 1]`까지가 마지막 4개 재료
- `size -= 4`로 스택의 사용 범위를 줄이면, 다음 재료가 제거된 위치부터 덮어써짐
- 예를 들어 `[2, 1, 1, 2, 3, 1]`에서 햄버거 하나를 포장하면 `[2, 1]`이 남음. 이후 `2, 3, 1`이 들어오면 남아 있던 `1`과 합쳐 햄버거를 하나 더 포장할 수 있음
