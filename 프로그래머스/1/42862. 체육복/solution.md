# 체육복
## 접근방식
- 학생 번호를 인덱스로 사용하는 배열을 만들고 체육복 수량을 1로 초기화
- lost에 있는 학생은 체육복 수량을 1 감소시키고, reserve에 있는 학생은 1 증가시킴
- lost와 reserve에 모두 있는 학생은 수량이 1이 되어 자신의 체육복만 사용
- 1번부터 n번까지 순회하면서 체육복이 없는 학생을 확인
- 앞번호 학생에게 여벌이 있으면 먼저 빌리고, 없으면 뒷번호 학생에게 빌림
- 체육복이 1벌 이상인 학생 수를 반환

## 사용한 알고리즘
- 그리디 알고리즘
- 작은 번호부터 처리하면서 앞번호의 여벌을 먼저 사용하여, 뒤에서 체육복이 필요한 학생의 대여 기회를 보존

## 시간 복잡도
- 전체 학생 수를 n이라고 할 때, 배열 초기화에 O(n)
- lost와 reserve의 길이는 각각 최대 n이므로 수량 반영에 O(n)
- 체육복 대여와 참여 학생 수 계산에 각각 O(n)
- 전체 시간 복잡도는 O(n)
- 학생별 체육복 수량을 저장하므로 추가 공간 복잡도는 O(n)

## 학습 메모
- `new int[n + 2]` : 학생 번호를 인덱스로 사용하고, 1번의 앞번호와 n번의 뒷번호도 배열 범위 안에서 확인할 수 있도록 생성
- `Arrays.fill(clothes, 1)` : 배열의 모든 값을 1로 초기화
- `clothes[student]--` : 도난당한 학생의 체육복 수량을 1 감소
- `clothes[student]++` : 여벌이 있는 학생의 체육복 수량을 1 증가
- 체육복 수량이 0이면 대여가 필요하고, 1이면 본인만 사용하며, 2이면 다른 학생에게 빌려줄 수 있음
- `else if`를 사용하여 앞번호에게 빌렸다면 뒷번호에게는 빌리지 않도록 처리
- 양 끝의 보조 칸은 수량이 1이므로 여벌이 있는 학생으로 취급되지 않음
- 입력 배열이 정렬되어 있지 않아도 학생 번호 순서로 배열을 순회하므로 별도 정렬이 필요하지 않음
