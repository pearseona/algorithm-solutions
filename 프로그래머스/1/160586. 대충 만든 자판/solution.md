# 대충 만든 자판

## 접근방식

- 알파벳별 최소 누름 횟수를 저장할 크기 26의 `count` 배열을 생성
- `keymap`의 각 문자열을 순회하면서 문자별 누름 횟수를 확인
- 문자열의 인덱스는 0부터 시작하므로 실제 누름 횟수는 `j + 1`로 계산
- 처음 발견한 문자이거나 기존보다 적은 횟수로 입력할 수 있으면 `count`를 갱신
- `targets`의 각 문자열을 순회하면서 문자별 최소 누름 횟수를 합산
- 입력할 수 없는 문자가 있으면 합계를 -1로 설정하고 해당 문자열의 검사를 종료
- 각 문자열의 결과를 `answer` 배열에 저장하여 반환

## 사용한 알고리즘

- 배열을 이용한 문자별 최솟값 저장
- 알파벳을 배열 인덱스로 변환하여 각 문자의 최소 누름 횟수를 미리 계산
- 목표 문자열을 확인할 때 저장된 값을 바로 조회하여 합산

## 시간 복잡도

- `keymap`에 포함된 전체 문자 수를 K, `targets`에 포함된 전체 문자 수를 T라고 할 때, 각각의 문자를 한 번씩 확인
- 전체 시간 복잡도는 O(K + T)
- 결과 배열을 제외한 추가 공간 복잡도는 크기 26의 배열만 사용하므로 O(1)
- 결과 배열을 포함한 공간 복잡도는 목표 문자열 개수를 N이라고 할 때 O(N)

## 학습 메모

- `new int[26]`으로 생성한 배열은 모든 값이 0으로 초기화됨
- 실제 누름 횟수는 1 이상이므로 0을 입력할 수 없는 문자를 나타내는 값으로 사용
- `key.charAt(j)`는 문자열에서 j번째 문자를 반환
- 문자에서 `'A'`를 빼면 `'A'`는 0, `'B'`는 1, `'Z'`는 25가 되어 배열 인덱스로 사용할 수 있음
- `count[index] == 0 || press < count[index]` 조건으로 처음 발견한 문자와 더 적은 횟수로 입력할 수 있는 문자를 처리
- 같은 문자가 여러 키에 있거나 한 키에 반복되어도 가장 적은 누름 횟수만 저장
- `total`은 목표 문자열마다 0으로 초기화하여 각 문자열의 결과를 독립적으로 계산
- `answer[i] = total`로 입력할 수 없는 경우도 결과 배열에 반영
