# 유연근무제

## 접근방식

- 직원별로 출근 희망 시각을 분으로 변환하고, 10분을 더해 출근 인정 시각을 계산
- 현재 요일을 `startday`로 설정하고 지각 횟수를 0으로 초기화
- 직원의 7일간 출근 기록을 순회
- 월요일부터 금요일까지는 실제 출근 시각을 분으로 변환하여 출근 인정 시각과 비교
- 출근 인정 시각을 초과했다면 지각 횟수를 1 증가
- 토요일과 일요일의 출근 기록은 검사하지 않음
- 하루를 확인할 때마다 요일을 1 증가시키고, 8이 되면 월요일인 1로 변경
- 7일을 확인한 뒤 지각 횟수가 0인 직원만 정답에 포함
- 상품을 받을 직원 수를 반환

## 사용한 알고리즘

- 구현 및 시뮬레이션
- 반복문으로 직원별 출근 기록을 확인하고, 요일을 하루씩 변경하며 평일의 지각 여부를 판단

## 시간 복잡도

- 직원 수를 n이라고 할 때, 직원마다 7일의 기록을 확인하므로 O(7n)
- 전체 시간 복잡도는 O(n)
- 직원 수와 관계없이 일정한 개수의 변수만 사용하므로 추가 공간 복잡도는 O(1)

## 학습 메모

- `schedules[i] / 100` : 출근 희망 시각에서 시를 구함
- `schedules[i] % 100` : 출근 희망 시각에서 분을 구함
- `hour * 60 + minute` : 시각을 분 단위로 변환
- 시각에 바로 10을 더하면 9시 58분이 968이 되므로, 분으로 변환한 뒤 10분을 더해야 함
- `timelogs[i][j]` : i번째 직원의 j번째 날 출근 시각
- `day <= 5` : 월요일부터 금요일까지만 출근 기록을 검사
- `arrival > limit` : 출근 인정 시각을 초과한 경우에만 지각 처리하며, 정확히 같은 시각이면 정상 출근
- `day == 8` 이면 1로 변경하여 일요일 다음 월요일로 처리
- day와 late는 직원마다 새로 초기화해야 각 직원의 기록을 독립적으로 확인할 수 있음
